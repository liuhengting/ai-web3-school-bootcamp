### Hardhat 3 部署合约到 Sepolia 笔记

#### 1. 核心理解

Hardhat 本身不是区块链节点，它是本地开发、编译、测试和部署工具。  
当我们部署合约到 Sepolia 时，Hardhat 会：

1. 编译 Solidity 合约，生成 ABI 和 bytecode；
2. 使用本地测试钱包私钥签名部署交易；
3. 通过 Sepolia RPC URL 把交易广播到测试网；
4. 等待交易确认；
5. 返回部署后的合约地址。

因此，部署测试网合约需要三样东西：

- Sepolia RPC URL
- 测试钱包私钥
- Sepolia 测试 ETH

RPC URL 通常来自 Alchemy、Infura、QuickNode 等 RPC Provider。普通开发者一般不会自己运行 Sepolia 节点，而是使用这些服务提供的节点入口。

#### 2. 初始化 Hardhat 工程

```shell
mkdir counter-demo
cd counter-demo
pnpm init
pnpm add -D hardhat
pnpm hardhat --init

# 如果 `pnpm hardhat` 不可用，可以使用：
pnpm exec hardhat --init
```

#### 3. 配置保密变量
Hardhat 3 可以使用 keystore 保存敏感配置：

```shell
pnpm hardhat keystore set SEPOLIA_RPC_URL
pnpm hardhat keystore set SEPOLIA_PRIVATE_KEY

--------

其中：
- `SEPOLIA_RPC_URL` 是 Alchemy / Infura 提供的 Sepolia endpoint；
- `SEPOLIA_PRIVATE_KEY` 是测试钱包私钥。

不要把私钥写进代码，也不要提交到 GitHub。

```

#### 4. 配置 hardhat.config.ts

```
import hardhatToolboxViemPlugin from "@nomicfoundation/hardhat-toolbox-viem";
import { configVariable, defineConfig } from "hardhat/config";

export default defineConfig({
  plugins: [hardhatToolboxViemPlugin],
  solidity: {
    profiles: {
      default: {
        version: "0.8.28",
      },
      production: {
        version: "0.8.28",
        settings: {
          optimizer: {
            enabled: true,
            runs: 200,
          },
        },
      },
    },
  },
  networks: {
    hardhatMainnet: {
      type: "edr-simulated",
      chainType: "l1",
    },
    hardhatOp: {
      type: "edr-simulated",
      chainType: "op",
    },
    sepolia: {
      type: "http",
      chainType: "l1",
      url: configVariable("SEPOLIA_RPC_URL"),
      accounts: [configVariable("SEPOLIA_PRIVATE_KEY")],
    },
  },
});
```

默认配置就已经携带Sepolia测试网相关配置

#### 7. 总结 

Hardhat 负责本地开发流程，RPC Provider 负责连接测试网节点，私钥负责签名交易，Sepolia ETH 用于支付 gas。   部署成功后，应记录合约地址、网络、ABI、部署账户和交易哈希，方便后续前端调用和区块浏览器验证。
