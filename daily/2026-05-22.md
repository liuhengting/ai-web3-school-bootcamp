## 本周学习总结（Week 1）

### AI 基础（5.18 - 5.22）

**Day 1（5.18）— LLM + Prompt**
- LLM 当做推理层不当做真相源：关键事实必须来自数据库、API、日志、文档源或其他可信系统
- Prompt 的价值在于把模糊任务变成模型可以稳定执行的工作说明
- Instruction 是给模型的任务规则，要回答：你是什么角色、要完成什么、不能做什么

**Day 2（5.19）— Context + RAG**
- Context 不是简单的长文本拼接，而是一套信息治理问题。要为每类信息标注来源、时效、权限和可信度
- RAG 系统至少有三次判断：文档怎么切、查询时取哪些内容、生成时如何引用和拒答
- 融合趋势：RAG + Agentic Search 结合使用

**Day 3（5.20）— Agent**
- Agent = LLM（大脑）+ 工具（手脚）+ 循环终止条件
- 一个真正可用的 Agent 必须知道自己能做什么、不能做什么、做完如何验证、失败如何停止
- LLM 是大脑，Agent 即是在计算机负责执行的手脚，使用 Agent 前要了解环境边界和业务背景
