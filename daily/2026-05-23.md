## 笔记 / 问题

### 智能合约
#### 🔑 核心知识点

- **Event vs Storage**：Event 是链外系统的可索引日志，Storage 是合约内部可读的状态。两者可靠性有链上共识背书，但 Event 合约本身无法读取，适合历史查询；Storage 贵但可被合约依赖。
- **索引器本质是缓存层**：历史 Event 永久存链上，任何人随时可回溯，后来的索引器不会缺数据，索引器篡改可用 `eth_getLogs` 验证。
- **Event 也消耗 Gas**：每个 topic 375 gas，每字节 data 8 gas，但远比 SSTORE（≈20,000 gas）便宜一个数量级。
- **智能合约的核心替换**：把"可信第三方"替换成"公开可验证的代码"。银行/交易所/托管机构的职能，由数学和密码学来完成。
- **Web3 复杂性靠设计兜底**：Web2 可以热修复，Web3 部署后无法修改，所有边界情况必须在部署前想清楚。

------

#### ❓ 疑问与回答

**Q1：通过索引 Event 构建查询数据库如何理解？**

索引器（如 The Graph）监听链上 Event 并写入普通数据库，前端用 SQL 查询，而不是每次扫链。类比：不是直播，而是录播，随时可从头看。

**Q2：先订阅 Event 的数据更全吗？**

不会。Event 永久写在链上，任何人随时可从合约部署块开始回溯，后来的索引器不会缺失历史数据。

**Q3：只有一个人索引，他篡改数据怎么办？**

原始数据在链上，任何人可用 `eth_getLogs` 直接验证。去中心化索引协议还有多方索引 + 质押惩罚机制。

**Q4：为什么 Event 查询比 Storage 快？**

Storage 存在 Merkle Patricia Trie，查历史需遍历每个区块。Event 存在区块 Receipt 里，自带 Bloom Filter，天然支持按类型高效过滤。

**Q5：智能合约的复杂性从哪里来？**

执行环境受限（无随机数/定时器/链外数据）、原子性双刃剑（重入风险）、状态公开（MEV 攻击面）、升级成本极高（Proxy 引入新风险）。

**Q6：真实业务场景里合约怎么用？**

- 稳定币转账 → ERC-20 原子转账，替代银行清算
- NFT 买卖 → 多合约原子协作，替代平台托管
- DEX 兑换 → AMM 公式自动定价，替代做市商
- 借贷协议 → 算法利率 + 自动清算，替代银行信贷部门


### 智能合约开发栈

#### 🔑 核心知识点

Hardhat：用 TypeScript 写测试，与前后端工程生态深度集成，适合全栈团队协作

Foundry：用 Solidity 写测试，内置 fuzz testing 和 fork testing，测试覆盖更深，速度更快，安全敏感合约首选

前端调合约：通过 viem / wagmi 直接与链交互，读操作走 RPC，写操作通过钱包签名广播

RPC 透明化：MetaMask 默认内置 Infura RPC，普通用户无需手动配置节点

后端的角色：不处理核心业务逻辑（合约负责），主要承担索引、缓存、RPC 代理等周边工程

#### ❓疑问与回答

Q：Foundry 更安全，是因为 Hardhat 测不出问题吗？

不是。区别在于测试深度和便利性。Foundry 的 fuzz 和 fork 测试内置且便捷，能覆盖更多边界情况；Hardhat 通过 JS 层模拟链上行为，写起来更繁琐，但并非不能保证安全。

Q：前端直接调合约，后端就不需要了吗？

不完全是。链上数据不适合历史查询，生产项目通常用后端跑索引器（如 The Graph）缓存 Event 数据；同时 RPC API Key 不能暴露在前端，需要后端代理。

Q：普通用户需要自己配 RPC 节点吗？

不需要。MetaMask 已内置默认 RPC，用户完全无感。只有开发者或高级用户才会手动更换节点地址。


### Web3 网络基础

#### 🔑 核心知识点

1. 多链生态

USDT 等稳定币在多条独立区块链上同时发行（Ethereum ERC-20、Tron TRC-20、Aptos 等），各链相互独立，转账必须确认收发两端在同一网络，否则资产丢失。

2. PoW vs PoS

PoW 用算力竞争出块，安全来源于电力和硬件消耗

PoS 用质押资产参与出块，安全来源于经济抵押（作恶即被罚没）

以太坊验证者质押 32 ETH，收入来自区块奖励、用户小费和 MEV，当前年化约 3～5%，质押总量越大单人收益越低

3. L2 与主网的关系

L2 是在主链之外执行交易、再批量提交回主链的扩展方案

L2 的主网不一定是 Ethereum，Bitcoin 有 Lightning Network，BNB Chain 有 opBNB

L2 用户体验确认快（秒级），但最终安全性依赖 L1，提现回主网可能需要数天

4. CEX 本质

中心化交易所在多条链上持有资产储备，用户内部转账只是数据库划账，不上链；只有提币到外部钱包才触发真实链上交易。

#### ❓ 疑问与回答

Q：转账选不同网络，手续费为何差这么多？

A：不同网络的 gas 机制、吞吐量、共识成本不同。Ethereum 主网最贵但最安全，Tron 几乎免费但中心化程度较高，L2 通过批量打包摊薄手续费。

Q：PoS 是否也有类似比特币 51% 攻击的风险？

A：有等效风险，但成本更高。控制以太坊 33% 质押量即可阻断最终性，66% 才能强行控制链，且一旦检测到恶意行为质押 ETH 会被协议直接罚没销毁。

Q：攻击者发动 51% 攻击能获利吗？

A：极难。攻击者必须先持有大量目标链原生资产，攻击曝光后该资产价格暴崩，加上质押被罚没，成本远超任何可能的收益。社区还可通过硬分叉让攻击者算力/质押失效，这是"Layer 0 社会共识"的最终保护。

Q：L2 交易确认比主网更慢吗？

A：用户感知更快，但最终安全性更慢。L2 内部秒级确认，但提现回 L1 需等待主网批量结算，Optimistic Rollup 甚至有 7 天挑战期——类似跨行转账须经央行清算。

Q：Aptos 是 Ethereum 的 L2 吗？

A：不是，Aptos 是独立 L1，有自己的共识机制（AptosBFT）和智能合约语言（Move），与 Ethereum 无从属关系。

Q：CEX 在不同链之间"换币"是怎么运作的？

A：CEX 在各主流链上持有资产储备，用户在平台内换币只是内部账本操作，不上链；提币时才从对应链的热钱包发出真实交易。

> AI金句：区块链的安全不只靠代码，还靠社会共识——攻击一个有价值的网络，最大障碍是"你必须先大量持有它，攻击成功后它立刻一文不值"。
